Blueprint Specs & Handoff

Generates visual specs for design handoff — it documents the anatomy, properties, layout, variables and styles of the selected components right on the canvas, to speed up the handoff between design, design systems and development.

How to use it

Select a component, component set or frame. In Specs choose what to include, tune the Options and Format, then press Create Spec. The result is drawn next to your selection.

Each spec answers a different question:

  • Anatomy — what the element is made of and which tokens each part uses.
  • Properties — the variants and their values.
  • Layout & Spacing — direction, alignment, padding, gaps and sizes.
  • Styling Inventory — the colors, typography and variables it applies.
  • Two-Way, Modes, Data (JSON) and Complete for deeper views.
